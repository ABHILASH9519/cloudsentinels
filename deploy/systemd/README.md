# Linux services

Prepared systemd units for a standalone Go API and one agent per cluster. Install the Linux binaries generated by the build script under `/opt/cloudsentinels/bin`. Create an unprivileged `cloudsentinels` service account, copy its private environment files to `/etc/cloudsentinels`, and configure the API inventory path and per-agent kubeconfig. The service user needs read access to those files and the cluster credentials. Use one instance file per registered agent. Install and enable the units only when ready to operate the stack. The Compose profile already manages these processes independently; the units are for the standalone host profile.
